# nicolasdahan.github.io

Source of [nicolasdahan.github.io](https://nicolasdahan.github.io/), built with [Eleventy](https://www.11ty.dev/) and deployed with GitHub Pages.

```
npm ci
npm run build
npm run serve
```

Publications come from `data/publications.bib`, other content from `data/*.yaml`.

Fonts: Be Vietnam Pro and Atkinson Hyperlegible Mono, under the SIL Open Font License (`src/assets/fonts/`).
